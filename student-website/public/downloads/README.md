# CampusOS Android APK

- `CampusOS-latest.apk` — always the current direct-download build
- `CampusOS-1.0.3-vc8.apk` — versioned copy of the same file

Refresh these from `student-app/dist/` after each EAS/local APK build.

Optional env overrides (see `.env.example`):

- `NEXT_PUBLIC_PLAY_STORE_URL`
- `NEXT_PUBLIC_APP_STORE_URL`
- `NEXT_PUBLIC_APK_URL` (CDN if the APK is hosted outside this site)
